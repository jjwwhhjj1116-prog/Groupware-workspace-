# 인력현황 파일 반입 및 권한 적용 원칙

원본 `2026년도 컨코스트,VIETQS 인력현황_260623.xlsx`는 로컬 저장소의
`private-data/workforce/`에만 보관하며 Git 추적과 클라이언트 번들에서 제외한다.

확인된 원본은 1개 시트, 총 92명(CON-COST 33명, VIETQS 59명), 14개 열로 구성된다.
연락처, 생년월일, 성별, 비상연락처는 일반 그룹웨어 화면이나 프런트엔드 초기 데이터로
반입하지 않는다.

그룹웨어 계정 초기화에는 다음 최소 필드만 관리자 승인 후 사용한다.

- 소속 법인
- 이름 / 영문 이름
- 부서명
- 직급
- 업무 이메일 식별자
- 사번(별도 발급 또는 검증된 값)

접근제어는 시스템 역할, 접근등급(L1~L5), 소속 부서, 담당 프로젝트를 함께 평가한다.
프런트엔드 메뉴 숨김은 편의 기능일 뿐 보안 경계가 아니므로, 운영 배포 시 동일 규칙을
인증 API와 모든 데이터 API에서 서버 측으로 다시 강제해야 한다.
